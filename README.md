Engage with us and become a collaborator! We need volunteers — and that could be YOU. Complete a simple task and learn how to make your first commit.

Help us attract volunteers. Just leave a trace that you were here!

## 🐨 How to Make Your First Commit (Super Simple Guide)
Preconditions:
- Logged in GitHub
- In editing mode
  
### 1. Open the README file
You're already here — perfect.

### 2. Add your name
Scroll to the “Contributors” section and add a line like:

- Your Name

### 3. Save your change
Click **Commit changes** at the bottom of the page.

### 4. Create a Pull Request
GitHub will show a button that says **“Propose changes”** or **“Create pull request.”**  
Click it.

### 5. Submit the Pull Request
Add a short message like:

Added my name to the README

Then click **Create pull request**.

### 6. Wait for review
A maintainer will approve and merge it.

### 7. You're done! 🎉
You just:
- Edited a file  
- Created a commit  
- Opened a pull request  
- Contributed to a project
